\# 3D Web Design



Create visually distinctive interfaces with depth and meaningful interaction.



\## Design principles



\- Establish a clear art direction before writing code.

\- Use one memorable visual focal point instead of many competing effects.

\- Combine typography, lighting, layering, perspective, and whitespace.

\- Avoid generic AI landing page templates and excessive gradients.

\- Use 3D only when it improves the product story.



\## Technology selection



\- Inspect package.json and existing components first.

\- Prefer CSS 3D transforms for lightweight depth effects.

\- Use Motion for React for transitions, hover interactions, and parallax.

\- Use Three.js and React Three Fiber for genuine interactive 3D scenes.

\- Do not add dependencies if existing tools can achieve the result.



\## Interaction design



\- Make objects respond naturally to pointer or touch input.

\- Use subtle rotation, depth, easing, and layered movement.

\- Keep primary text and calls to action readable.

\- Respect reduced-motion preferences.

\- Provide fallbacks for mobile and devices without WebGL support.



\## Implementation



\- Preserve the existing React or Next.js architecture.

\- In Next.js, isolate browser-dependent 3D code in client components.

\- Lazy-load heavy scenes where appropriate.

\- Avoid unnecessary rendering, expensive effects, and oversized assets.

\- Keep the interface responsive and functional.



\## Finish



Implement the actual requested interface, not just a design proposal.

Run the existing build when appropriate and report any remaining issues.
